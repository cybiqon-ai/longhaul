# Code of conduct

Be decent. Assume good faith. Critique the code, not the person.

Harassment, personal attacks, and sustained disruption are not welcome and will
get you removed from the project's spaces.

Report a problem to **pyguru123@gmail.com**. Reports are handled privately.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/);
that document is the reference where this one is silent.
